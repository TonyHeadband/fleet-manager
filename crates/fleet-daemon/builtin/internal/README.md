# Internal resources

Private design docs and working notes for this product. Never published.

## Layout

- `specs/` — designs (`YYYY-MM-DD-<topic>-design.md`). Written by the user and Claude sessions.
- `plans/` — implementation plans (`YYYY-MM-DD-<topic>.md`) and their ledgers (`…-ledger.md`).
- `tasks/` — one folder per task (`tasks/<task-name>/`). Written by Fleet Manager's orchestrators and merged when the
  task opens its PR.
- `docs/` — internal notes and product knowledge. Any author.
- `scripts/` — dev scripts that never ship.

Each folder has a `README.md` with the details.
