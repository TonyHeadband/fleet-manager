# Bundled fonts

All SIL Open Font License 1.1; each family's licence is the `LICENSE-*.txt` beside it. Every file is a static
instance (no `fvar` table): egui draws a variable font only at its default instance, so it could not stand in for
Medium. Settings › General picks the UI font and the mono font separately.
