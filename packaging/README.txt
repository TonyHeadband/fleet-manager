fleet-manager

Start it by running fleet-gui.

The first run checks that Git, Claude Code and gh are installed and offers to install the ones that are missing.

Windows: if SmartScreen says "Windows protected your PC", click "More info" and then "Run anyway".

To update: close fleet-manager (stop its daemon in the close dialog), then unzip the new version over this folder.
Your settings, tasks and personas live in your user folders, so they stay.

Documentation: https://tonyheadband.github.io/fleet-manager/
