## What's new in v0.2

- **Windows support**, alongside Linux (Rocky/RHEL 8 and newer).
- **One archive per system**: unpack and run, nothing installed system-wide.
- **Setup wizard** checks for Git, Claude Code and GitHub CLI, and offers to install what's missing.
- **Built-in agent terminals** replace tmux; **Open in terminal** takes over an agent, and agents resume after a
  restart.
- **Update notice** when a new version is out.
